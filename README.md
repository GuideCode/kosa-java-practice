## 🚀 Introduction
KOSA 전자정부 표준 프레임워크 기반 공공프로젝트 개발 전문가 양성과정 중 진행한 일일 미션과 과제 풀이 코드를 정리한 저장소입니다. 게시판, 도서관 관리, 전화번호부, 쇼핑몰, 레스토랑 주문 시스템 등 다양한 주제의 미니 프로젝트를 통해 객체지향 설계와 컬렉션 활용을 연습한 기록입니다.

---

## ✨ Features

* 📋 **게시판 프로그램 (Board)**
  글 등록/조회 기능을 가진 간단한 게시판 CRUD 예제 (`board`)

* 🗂️ **컬렉션 미션 (Data)**
  `List`, `Map`, `Stack`을 활용한 데이터 처리 미션 (`data`)

* 📚 **도서관 관리 시스템**
  도서 및 회원 정보를 관리하는 대출/반납 프로그램 (`task/library`)

* 📞 **전화번호부 시리즈**
  요구사항을 단계적으로 발전시킨 전화번호부 관리 프로그램 (`task/phoneBook`, `phoneList`, `phoneNum`, `phoneStream`)

* 🍞 **주문 관리 미션**
  빵집 주문 처리(`task/bread`), 카페/음식 대기열 처리(`task/queueOrder`), 레스토랑 코스 메뉴 주문(`task/restaurant`) 등 실생활 기반 주문 시스템 실습

* 🛍️ **쇼핑몰 & 도서 미션**
  상품 카테고리와 회원 등급 관리(`task/shoppingMall`), 도서 정보 관리(`task/book`) 예제

* 🎮 **숫자야구 게임**
  숫자 야구 게임 로직 구현 미션 (`task/baseball`)

* 🔤 **문자열 & 반복문 미션**
  문자열 찾기/뒤집기 등 문자열 처리(`task/string`), 반복문 활용 문제 풀이(`task/loop`)

* 💾 **파일 입출력 미션**
  파일 읽기/쓰기 및 유틸리티 클래스 실습 (`task/io`)

* 🗣️ **인터페이스 활용 미션**
  `Speakable` 인터페이스를 구현한 다형성 실습 (`task/speak`)

* 🎬 **동영상 대여 관리**
  회원별 동영상 대여 정보를 관리하는 프로그램 (`task/video`)

## 📂 Folder Structure

```plaintext
kosa-java-practice/
└── KOSA_Study/
    └── src/
        ├── board/            # 게시판 CRUD 프로그램
        ├── data/             # List, Map, Stack 컬렉션 미션
        ├── review/           # 자료형 복습 (IntegerType)
        └── task/
            ├── baseball/     # 숫자야구 게임
            ├── book/         # 도서 정보 관리
            ├── bread/        # 빵집 주문 처리 미션
            ├── io/           # 파일 입출력 미션
            ├── library/      # 도서관 대출/반납 시스템
            ├── loop/         # 반복문 활용 문제 풀이
            ├── phoneBook/    # 전화번호부 관리 (심화)
            ├── phoneList/    # 전화번호부 관리 (리스트 버전)
            ├── phoneNum/     # 전화번호부 관리 (기초)
            ├── phoneStream/  # 전화번호부 관리 (Stream 활용)
            ├── queueOrder/   # 주문 대기열 처리 미션
            ├── restaurant/   # 레스토랑 코스 메뉴 주문 시스템
            ├── shoppingMall/ # 쇼핑몰 카테고리/회원 등급 관리
            ├── speak/        # 인터페이스 다형성 미션
            ├── string/       # 문자열 처리 미션
            └── video/        # 동영상 대여 관리 프로그램
```
